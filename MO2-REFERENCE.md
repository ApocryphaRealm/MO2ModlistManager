# MO2 reference - what Mod Organizer 2 does where the Modlist Manager touches it

Standing rule (the owner, 2026-09-23): before adding to or altering an MO2 feature, read MO2's own implementation at the
release tag and follow its shape. Read 2026-09-26 for MO2 **2.5.2** (the version the owner's instances run).

## What MO2 does

| Feature | MO2 |
|---|---|
| modlist.txt | `# This file was automatically generated by Mod Organizer.` then one line per mod, highest priority first (the priority order inverted), `+` enabled, `-` disabled, `*` a foreign mod (DLC, CC), CRLF, UTF-8; written only when the content differs (`commitIfDifferent`) |
| plugins.txt | the same header; plugins sorted by priority; the game's PRIMARY plugins (`GameSkyrimSE::primaryPlugins`: skyrim.esm, update.esm, dawnguard.esm, hearthfires.esm, dragonborn.esm, plus every line of Skyrim.ccc in the game folder - none when there is no Skyrim.ccc, as in a Stock Game without one) are left out entirely; `*name` for an active plugin, `name` for an inactive one; CRLF; the SYSTEM code page (not UTF-8); not saved at all when it would be empty |
| loadorder.txt | every plugin in priority order, primary plugins included, no stars, UTF-8, CRLF |
| lockedorder.txt | `name|priority` lines for locked plugins |
| a separator | an ordinary mod folder named `<name>_separator`, created through `createMod` (a folder with a meta.ini), placed at the priority the user picked; ModInfo recognises it by the `_separator` suffix alone |
| category | `category="<primary>,<others>"` in meta.ini's [General], written with every other meta field by QSettings |
| toolbar | `ui->toolBar` from the .ui file; action menus (Tools, Help, ...) are InstantPopup; a spacer before the last separator right-aligns the links; pinned executables are `custom__*` actions MO2 removes and re-inserts on every executables change. Plugin tools live in the Tools menu (`actionTool`); MO2 has no API for a plugin's own toolbar button |

## What the Modlist Manager does, and how it follows MO2

| Feature | Modlist Manager |
|---|---|
| modlist.txt | the same header, bottom-first order, `+` / `-`, CRLF, UTF-8 (`write_modlist`); read with `utf-8-sig` (`read_modlist`); the foreign `*` mods read apart (`read_foreign`) and written back after the rest, lowest priority, in their order; a planned separator that matches an existing folder in all but letter case keeps the existing spelling (one folder on Windows) |
| plugins.txt | the same header and CRLF; every plugin in the planned order with `*` (every plugin left in a mod's root is meant to load - what must not load is moved to Optional ESPs) except the primary plugins (`primary_plugins`: the same five and Skyrim.ccc from the instance's gamePath), which are left out; the system code page (`mbcs`); read as UTF-8 when it is, else the code page (`_read_text`); never written empty |
| loadorder.txt | the planned order, primary plugins included, the same header, CRLF, UTF-8; never written empty |
| a separator | a folder `<name>_separator` with a meta.ini (modid 0, category 0, the colour the list's existing separators use); retired separators are moved into the Apply backup, never deleted |
| category | `category="<id>,"` - the form saveMeta writes - replacing only that line and keeping every other line as it was |
| toolbar | its own QAction inserted before Settings on the first QToolBar, re-inserted when MO2 rebuilds the toolbar (checked every 2 s); object names `MO2ModlistManagerAction` / `MO2ModlistManagerBtn`, so it is never mistaken for a `custom__` executable; the icon painted in the colour Qt's stylesheet style resolves for the button (palette ButtonText), repainted when it changes |

## Departures

None known. The four found when this file was first written (primary plugins written to plugins.txt, UTF-8 instead
of the system code page, foreign `*` mods dropped from modlist.txt, no empty-list guard) were fixed in 1.0.0 before
its release, 2026-09-26, and tested by an Apply on scratch copies of Njordlinger Test and the Apostasy author's list
(three foreign mods kept) and by a unit test of the Skyrim.ccc path.
