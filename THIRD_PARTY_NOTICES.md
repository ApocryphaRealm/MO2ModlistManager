# Third-party notices - MO2 Modlist Manager

## Mod Organizer 2

The plugin runs on the Mod Organizer 2 Python plugin API (https://github.com/ModOrganizer2/modorganizer, GPL-3.0) and
the PyQt bindings MO2 ships. It contains no code from Mod Organizer 2.

## Apostasy (reference for the ordering rules)

Ten of the ordering rules were read off the load order of **Apostasy**, a Wabbajack modlist by Oghma-Infinium
(https://github.com/Oghma-Infinium/Apostasy, https://www.nexusmods.com/skyrimspecialedition/mods/118893): how its
author grouped and ordered mods, measured on the list's own files. The plugin ships none of Apostasy's files, lists or
data; the rules are written in this plugin's own code. Apostasy is not affiliated with this plugin.
